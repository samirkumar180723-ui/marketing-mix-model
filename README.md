# Marketing Mix Model & Budget Optimizer

An end-to-end Marketing Mix Model (MMM): fits adstock (carryover) and
saturation (diminishing returns) curves per channel, validates them against
known ground truth, and optimizes budget allocation — with a safeguard
against a real, common MMM failure mode: extreme, unreliable reallocation
recommendations driven by weakly-identified parameters.

## ⚠️ Data disclosure

All data is **synthetic**, generated by `src/data_generator.py` with known,
documented ground-truth adstock/saturation parameters per channel (see
`TRUE_PARAMS`). This lets every fitted parameter be checked directly against
the true value that generated the data — the validation step this project is
built around.

## What this project does

1. **Generates** 104 weeks of sales data driven by baseline trend/seasonality
   plus 4 marketing channels (TV, Digital, Social, Print), each with adstock
   carryover and diminishing-returns saturation.
2. **Fits** each channel's adstock decay and saturation curvature via grid
   search, using **coordinate descent** across channels (fixing the critical
   bug where searching each channel independently caused it to falsely
   absorb other channels' true contributions — see Methodology below).
3. **Validates** fitted parameters against the known ground truth.
4. **Optimizes budget allocation** two ways:
   - An unconstrained mathematical optimum (cross-validated via two
     independent methods: SLSQP and greedy marginal allocation)
   - A **realistic, bounded recommendation** that caps reallocation to a
     sensible range of current spend — because the unconstrained optimum
     in this project recommended shifting 99% of budget into one channel,
     which is a classic symptom of extrapolating a weakly-identified
     response curve, not a real business opportunity.

## A real methodological fix, documented honestly

The first version of the per-channel parameter search fit each channel's
curve independently, omitting the other channels from the regression. This
caused each channel's search to wrongly absorb the other channels' true
contribution as if it were its own — visibly distorting recovered parameters
(e.g., one channel's fitted decay was 0.70 vs. a true value of 0.40). This was
diagnosed and fixed with a coordinate-descent approach that controls for all
other channels' current best-fit curves while searching each one — a standard
technique when jointly estimating correlated nonlinear parameters.

## An honest, reported limitation

Two channels' fitted saturation curvature (alpha) land on the search grid's
boundary, indicating these channels' diminishing-returns curve is **weakly
identified** from this spend data. This is a known, real limitation in MMM
practice (not unique to this synthetic example) — curvature is hard to pin
down when a channel's historical spend hasn't varied over a wide enough
range. It's surfaced explicitly in the dashboard rather than hidden.

## Project structure

```
mmm_project/
├── app.py                      # Streamlit dashboard (entry point)
├── requirements.txt
├── data/
│   └── mmm_data.csv             # generated by data_generator.py
└── src/
    ├── data_generator.py         # synthetic data with known ground truth
    ├── mmm_fit.py                 # adstock/saturation fitting (coordinate descent)
    └── budget_optimizer.py        # budget allocation (unconstrained + bounded)
```

## Running locally

```bash
pip install -r requirements.txt
python src/data_generator.py
streamlit run app.py
```
